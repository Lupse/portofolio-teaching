# Simple Portfolio Website

## About the Project

This project is a simple personal portfolio website created for educational purposes. It is designed to help students understand the basic concepts of web development using HTML, CSS, and JavaScript.

The website introduces a personal profile, presents a list of projects, and provides contact information. It also includes a simple interactive button to demonstrate how JavaScript works.

## Technologies Used

- **HTML** – Defines the structure and content of the website.
- **CSS** – Controls the website's appearance, layout, colors, and responsiveness.
- **JavaScript** – Adds simple interactions and makes the website respond to user actions.

## Features

- **Navigation Bar:** Allows users to move between different sections of the website.
- **Home Section:** Introduces the website owner.
- **About Section:** Provides a short personal introduction.
- **Projects Section:** Displays sample projects.
- **Contact Section:** Shows contact information and an interactive button.
- **Responsive Design:** Adjusts the layout for smaller screens, such as mobile phones.

## Project Structure

```text
portfolio/
├── index.html
├── style.css
└── script.js
```

- `index.html` contains the website structure.
- `style.css` contains the styling rules.
- `script.js` contains the JavaScript functions.

## Learning Objectives

By studying this project, students will learn how to:

1. Create a basic website using HTML elements.
2. Apply CSS to improve the website's appearance.
3. Use Flexbox to arrange elements on a page.
4. Create navigation links between website sections.
5. Write simple JavaScript functions.
6. Use JavaScript to respond to button clicks.
7. Build a responsive layout for different screen sizes.

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in a code editor, such as Visual Studio Code.
3. Open `index.html` in a web browser.
4. Explore the website and test the interactive button.

No additional installation or external libraries are required.

## Purpose

This project is intended as a starting point for learning web development. The code is kept simple and organized so that students can understand each part and experiment with it independently.

**Note:** This is a learning project, not a production-ready portfolio website. The contact section is for demonstration purposes and does not include a working contact form.
